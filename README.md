# 📊 Movie Success Analysis

## 📌 Description
This project analyzes factors that influence movie success.

## 🛠 Technologies
- Python
- NumPy
- Pandas
- Matplotlib / Seaborn

## 🔍 What was done
- Data cleaning
- Exploratory Data Analysis (EDA)
- Correlation analysis
- Spearman test

## 📈 Results
- Budget affects revenue but is not the only factor
- Some low-budget movies are highly profitable
